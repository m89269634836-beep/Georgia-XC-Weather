# XC v3 — проверка гипотезы многодневных погодных аналогов (21.11.2026)

## Что обнаружено при повторном чтении пользовательского XContest JSON
У каждого из 1012 JSON есть зачётная маршрутная дистанция `league.route.distance` (км). Модель v2 ошибочно пыталась прогнозировать лишь GPS-прокси динамического парения и термических спиралей, а не маршрутную дальность. Маршрутная дальность — целевая переменная для XC-режима; отдельно вести модель динамического удержания и риски.

С 2024 года: 197 сочетаний старт-дата, включая 117 многопилотных дат (502 полёта). Однопилотные удачные дни содержат ценные *положительные* наблюдения, но не публикуются как потенциально идентифицируемые строки агрегата, пока не решён более строгий подход к приватности.

Из всех 197 событий 2024–26 лишь 23 имели хотя бы один маршрут >=100 км; 13 имели q75 дистанции >=100 км. Среди 117 многопилотных дней q75>=100 км только 8 случаев (0 за 2024, 5 за 2025, 8 за 2026 по всей 197-дневной выборке). Поэтому модель редких «выдающихся» XC-дней пока малообучена.

## Эксперимент v3 с последовательностью погоды
- 117 многопилотных site/day для обучения и тестирования; маршрутный результат — `q75_route_km` и `median_route_km`. Одна сверхдальняя запись не определяет целиком качество дня.
- Из Open-Meteo ERA5 получена ежедневная последовательность за D-5,...,D-1 для всех 117 дат: 16/16 site/year групп, без ошибок. Погодные переменные: ветер (скорость и направления с векторным кодированием), давление, температура, осадки, радиация и облачность. Есть тенденции давления/температуры/облачности.
- День D0 — ECMWF IFS025 24-часовой фиксированный прогноз, действительно предшествующий дню полёта, согласно Previous Runs.
- 2024-2025 (71 многопилотный день) — обучение, 2026 (46) — годовая отложенная выборка.
- Предзаданы три аналоговых эвристики: site/season, D0-weather nearest analogs, D-5..D0 weather sequence nearest analogs. Параметры не подбирались по 2026.
- **Итог для q75 маршрутной дистанции**: MAE 26.17 / 27.30 / 28.86 км; многодневные аналоги хуже однодневных на 1.56 км, 95% day-bootstrap интервал эффекта [-3.78, +0.62] км включает ноль.
- **Итог для медианного маршрута**: MAE 21.31 / 21.92 / 22.88 км.
- Нет доказанного улучшения. **Не включать v3-аналоговый рейтинг в оперативную модель, пока не подтвердится на будущих датах.**

### Что эти цифры НЕ доказывают
Это НЕ отрицание физического влияния предшествующей атмосферной эволюции. ERA5 — постфактум reanalysis, становится доступен с задержкой. Одноточечная ежедневная статистика не описывает пространственные карты фронтов и циркуляции, устойчивые слои, направление ветра относительно склонов и XC-коридоров. При 71 обучающей погодной ситуации простая метрика близости может находить ложные аналоги. Кроме того, длинный маршрут зависит от пилота, крыла, решения о полёте и публикации трека.

### Реальный следующий этап
1. Две отдельные истории: **эволюция фактической погоды** D−5...D−1 и **как пересматривался прогноз на D0** в моделях D−5/D−3/D−2/D−1. Open-Meteo Previous Runs и Single Runs поддерживают выбор фиксированного lead и конкретного выпуска ECMWF.
2. Синоптические карты давления/геопотенциала 500/700/850 гПа, изменение направления ветра с высотой, влажность, радиация/почва/BLH, дождь накануне; вдоль рабочего XC-коридора (несколько точек), а не одна модельная ячейка на старте.
3. Привязать GPS-треки к **фактическим стартовым площадкам и участкам маршрута** и объединить с рельефом (наветренность, ущелья, WindNinja как пространственный признак). Разделить летний XC и зимний динамик, различать разные грани Гудаури.
4. Использовать 197 site/day 2024+ и довоенный архив 2013–23 через reanalysis только для поиска режимов (не для прямого сравнения as-issued), учитывать одиночные выдающиеся маршруты как положительные и не делать отрицательных примеров из дней без публикации.
5. Кластеризовать реальные синоптические режимы и искать аналоги при малом числе признаков; оценить на полностью отложенном будущем сезоне/месяцах, а не оптимизировать по уже увиденному 2026.
6. Прогноз: потенциальная достижимая XC-дальность, вероятность интервала дистанций **условно на осуществившийся полёт**, пригодность динамического гребня и раздельный блок безопасности. Никакая метрика не является разрешением на взлёт.
7. Для вероятности хорошего дня среди ВСЕХ календарных дней нужны явные данные о попытках, несостоявшихся полётах, причинах отказа, местных ветрах; отсутствие XContest записи не значит плохую погоду.
